Data quality & methodology

Validation diagnostics and explicit assumptions used in event construction.

Diagnostics

Analytical assumptions

  • Records are sorted by parsed timestamp; exact duplicate rows are identified and excluded from event construction, but remain visible in raw records.
  • Episodes are consecutive runs of the same ActivitySet/ScreenType/ObjectInFocus state. Missing values are retained as “(missing)” for segmentation.
  • Episode duration is estimated from first to last observed timestamp plus the median positive sampling interval, capped at 10 seconds to avoid inflating gaps.
  • Active interaction duration is an estimate based on non-menu/non-idle activity records; it is not direct evidence of continuous physical manipulation.
  • Connectivity percentage uses non-empty Status values and classifies values containing “connect”, “true”, “1” or “online” as connected.
  • Spatial differences are calculated between consecutive valid non-placeholder vectors. Rotation uses wrapped Euler component differences.
  • Frequent sequence support is an occurrence count within the filtered session. Statistical significance is not calculated.
  • Zero vectors in inactive screens are treated as likely placeholders for spatial summaries, not automatically as meaningful movement.
